# Contributing practical feedback

This project is intended to improve through feedback from cargo colleagues and learners.

A useful report includes:
- the page or feature;
- what you tried, using fictional values;
- the result you expected;
- what happened;
- one practical improvement and why it would help.

Use only fictional or fully recreated examples. Do not upload work documents, customer information, real shipment references, login details or screenshots containing sensitive information to GitHub issues.

Small contributions are welcome. Describe the behaviour you want to improve, keep the change focused and explain how you checked it. Use the existing English/German pairs for new interface text. Preserve human-review boundaries and label future capabilities honestly.

Before real operational deployment, the owner must define authorised users, approved procedures, evidence requirements, retention and deletion, incident handling and the permitted integrations. This public preview is for learning and feedback.
